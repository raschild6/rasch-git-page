Windows Installation

Install Rasch-Git on Windows with the setup wizard.

  1. Download the .exe installer. Download it from the Releases page or the Home page.
  2. Run the installer. Windows SmartScreen may show a warning because the app is not code-signed yet.

    This is normal. Every release is scanned on VirusTotal — see the links on the Releases page.

  3. Click More info → Run anyway in the SmartScreen dialog.
  4. Follow the setup wizard to complete the installation.
  5. Launch Rasch-Git from the Start Menu or the desktop shortcut.

macOS Installation

Install Rasch-Git on macOS from the .dmg disk image.

  1. Download the .dmg file. Download it from the Releases page or the Home page.
  2. Expect a Gatekeeper warning. macOS Gatekeeper may block the app because it is not code-signed yet.

    This is normal — the steps below tell macOS you trust the app.

  3. Open Finder, locate the downloaded .dmg, then right-click → Open.
  4. If it is still blocked: go to System Settings → Privacy & Security, scroll down and click Open Anyway.
  5. Alternatively, run in Terminal:
    xattr -cr /Applications/RaschildGitManager.app
  6. Drag the app to the Applications folder.
  7. Launch Rasch-Git from Applications or Spotlight.

First Launch

Get up and running the first time you open Rasch-Git.

  1. Follow the welcome guide. On first launch the app opens with a welcome/onboarding guide.
  2. Make sure Git is installed on your system. To verify, run in a terminal:
    git --version
  3. Connect your account (optional) in Edit → Accounts & SSH Keys…. Sign in to GitHub is all it takes for pushing, pull requests, CI status, issues and cloning from your account. For GitLab, add an access token with the api scope (read_api is enough if you only want to read). Bitbucket and other hosts work with a token for push and pull; their pull requests open on the website.
  4. Open a repository, or clone one with File → Clone… — paste a URL, or pick a repository from your GitHub or GitLab account's tab.

Optional: Git LFS

Repositories that store large files with Git LFS need Git LFS installed. On Windows it already comes with Git for Windows. On macOS, install it with Homebrew or the official installer from git-lfs.com:

brew install git-lfs

Rasch-Git detects LFS repositories by itself and shows a banner if Git LFS is missing or not set up for a repository.

Troubleshooting

Common problems and how to fix them.

  • “App is damaged and can’t be opened” (macOS)

    Run xattr -cr on the app bundle:

    xattr -cr /Applications/RaschildGitManager.app

  • SmartScreen blocks every launch (Windows)

    Right-click the .exe → Properties → check Unblock, then click OK.

  • The app doesn’t detect Git

    Make sure Git is installed and available in your system PATH. Restart Rasch-Git after changing it.

  • Something else?

    For other issues, open an issue on GitHub.
