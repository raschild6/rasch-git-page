Features

Built for real-world Git workflows

Powerful tools that stay out of your way, from everyday commits to massive repositories.

Fully Async GUI

Every operation runs in the background, the interface never locks up.

Smart Diff Views

Hunk, Inline, and Split views with syntax highlighting and horizontal scroll.

Built-in Terminal

Integrated shell per repo tab, right where you need it.

Auto Fetch & Real Progress

Background fetch with live progress tracking and cancel support.

Bulk Branch & Repo Management

Perform actions on multiple branches or repos at once with summary reports.

Conflict Resolution

Visual conflict editor with guided merge workflow and auto-stash on checkout.

Commit Graph Virtualization

Smooth scrolling through massive commit histories.

Tab Grouping

Organize open repos into collapsible groups for easy navigation.

Commit Search

Search through commit titles and descriptions instantly.

Customizable Commit Templates

Preconfigured commit messages with placeholders, managed from Settings.
