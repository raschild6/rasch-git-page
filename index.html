Features

Built for real-world Git workflows

Every feature, grouped by what it does for you. Click any card for the details.

Speed & Reliability

Fully Async GUI

Every Git operation runs in the background — the window never freezes.

Virtualized Commit Graph

Smooth scrolling through huge histories, with stashes and uncommitted work in the graph.

Auto Fetch with Progress & Cancel

Always up to date, real progress bars, and a cancel button that actually stops Git.

Consistent Cross-Platform Look

Same layout and sizes on Windows and macOS, no overlapping controls.

Safety

Undo / Redo

Undo commits, checkouts, resets, discards, stashes and more — safely.

Interactive Rebase

Reorder, reword, squash or drop commits visually — and undo the whole rebase in one step.

Review Before Commit

Merges and cherry-picks are staged for review, never committed behind your back.

Git-flow, Built In

Start and finish features, releases and hotfixes with a checklist of every step — no extension to install, every merge reviewed.

Safe Checkout

Checkouts carry your changes across automatically.

Conflict Resolution

Resolve conflicts line by line.

Hunk-Level Staging

Stage or unstage individual hunks right from the diff.

Scale

Tab Groups

Organize many repositories into coloured, collapsible groups on their own row; hide tabs without closing them.

Split View

Several repositories side by side: up to four in one window, each one live.

Worktrees

Work on two branches at once: open any branch in its own folder and tab, without stashing.

Bulk Branch & Repo Actions

Delete, pull or merge many branches — or act on every open repo — in one go.

One Tree for Every Ref

Branches, remotes, tags, stashes and a detached HEAD in one filterable tree.

Submodules

Every submodule's state at a glance — update, open, add or remove them, and read "moved by N commits" instead of a raw pointer diff.

Large Files (Git LFS)

Big design files, media or datasets just work: download progress, real sizes, no pointer text.

Commit Search

Find any loaded commit by message, author or hash, instantly.

Deep Search

Find any file — or any line of code — across every branch and the whole history.

Blame & File History

Who changed each line and why — and every version of a file, renames included.

Drag & Drop to Open

Drop repository folders on the window to open them — several at once.

Action Scheduler

Fetch, pull (keeping local changes), push or run your own commands automatically, on a schedule.

Your Workspace

Built-in Terminal

A real shell in every repository tab, already in the right folder.

Custom Toolbar Buttons

Put your own commands, scripts and links one click away.

Custom Themes

Dark, Light, or your own theme from five colours, with a live preview.

Commit Templates

Pre-filled commit titles with your version and branch.

Smart Diff Views

Hunk, Inline or Split — one click to switch, with syntax highlighting and search; changed images compared before / after.

Commit Details

Author avatar, copyable SHA, full message and changed files at a glance.

External Editors

Open any file — or any committed version of it — in the app you choose.

Guided Feature Tour

A skippable tour points at each feature in the real app.

Integrations

Pull Requests Without Leaving the App

Create, review, check out and merge pull requests — and see whether CI passed on your branches, commits and pushes.

Clone & Fork from Your Account

Pick a repository from your GitHub or GitLab account instead of copying a URL — or fork it and clone your fork in one step.

Issues → Branches

Your issues next to the graph — start a well-named branch from one in a click, and always see which issue you're working on.

Trust

VirusTotal-Scanned Installers

Each installer is scanned on VirusTotal at release time.

Verified Automatic Updates

Get notified of new versions, then download, verify and install in one click.

Activity Log & Full Logs

See everything the app did; export every Git command's raw output.

GitHub Authentication

Sign in to GitHub once — or add a token or an SSH key — and push just works.

Signed Commits

Get the Verified badge: sign with an SSH or GPG key, set up, tested and added to GitHub from one page.
